# Lesson 1: TypeScript Kya Hai?

## Overview
TypeScript ek programming language hai jo JavaScript ka upgraded version hai.
Is mein aapko types define karne ka option milta hai jisse code zyada safe aur error-free banta hai.

## TypeScript Ka Formula
```
TypeScript = JavaScript + Types
```

## Key Features
- **Static Type Checking**: Variables ko types assign kar sakte hain
- **Error Prevention**: Compile-time par errors pakad leta hai
- **IDE Support**: Better autocomplete aur suggestions milte hain
- **Modern JavaScript Features**: Latest JavaScript features ko support karta hai

## Simple Example
```typescript
// JavaScript mein:
let name = "Ali";
name = 5;  // JavaScript mein yeh allowed hai (galti bhi ho sakti hai)

// TypeScript mein:
let name: string = "Ali";
name = 5;  // TypeScript compile time par error dega
```

## TypeScript vs JavaScript
| Feature | JavaScript | TypeScript |
|---------|------------|------------|
| Type Checking | Run-time par | Compile-time par |
| File Extension | .js | .ts |
| Learning Curve | Easy | Moderate |
| Error Detection | Late (runtime) | Early (compile time) |
